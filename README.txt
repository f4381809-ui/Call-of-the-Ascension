Карта истоков v20 — Supabase

1. Supabase → SQL Editor → выполнить supabase-setup.sql.
2. Authentication → Users → Add user → создать email и пароль, подтвердить email.
3. В SQL Editor выдать роль (заменить email):
   insert into public.map_admins(user_id)
   select id from auth.users where email='ВАШ_EMAIL'
   on conflict do nothing;
4. Загрузить index.html в корень GitHub-репозитория, связанного с Vercel.
5. Открыть сайт, нажать Админ → Войти и указать email и пароль.
6. Проверить на другом устройстве изменение названия мира/истока. Обновления опрашиваются каждые 5 секунд.

Важно: общими являются только истоки, зоны, категории, названия миров и настройки.
Игроки и перемещения хранятся локально в каждом браузере. Перемещение игроков доступно только админу этого браузера, но не транслируется другим пользователям.
Серверная безопасность: RLS + проверка администратора внутри RPC save_map_state.
Не публикуйте service_role/secret ключи.
